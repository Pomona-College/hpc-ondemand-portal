## Common Learner Patterns

### Pattern 1: "I just want to run my code"
These learners want quick results with minimum complexity. They appreciate that OnDemand gets them computing faster without SSH mastery.

### Pattern 2: "I like to understand systems"
These learners want to know *why* things work this way. Connecting OnDemand features to underlying SLURM helps them learn better.

### Pattern 3: "I prefer graphical interfaces"
These learners gravitate toward OnDemand immediately and may never feel comfortable with SSH. Help them succeed with graphical tools.

### Pattern 4: "I want to be a power user"
These learners see OnDemand as stepping stone to SSH and advanced HPC. Encourage them toward next workshops.

## Differentiated Support

### For Complete Beginners
- Extra emphasis on dashboard navigation
- Pre-recorded tutorials for review
- Hands-on help with first file upload
- Celebrate small wins

### For Experienced Linux Users
- Skip basic terminal coverage
- Focus on OnDemand-specific features
- Faster pace through file management
- Early GPU computing introduction

### For ESL Learners
- Clear written instructions in addition to verbal
- Visual demonstrations with minimal speech
- Extra breaks for processing time
- Contact info in multiple formats

## Tips for Instructors

- Recognize that not everyone arrives at HPC with same background
- Learner profiles help anticipate questions and needs
- Create multiple examples for different research areas
- Have both fast and slow paths through material
- Celebrate diverse backgrounds learners bring
