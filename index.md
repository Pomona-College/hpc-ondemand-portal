Welcome to the OnDemand Portal Orientation workshop! This training teaches you how to access Sagehen HPC resources through a web browser interface without requiring SSH knowledge.

## What You Will Learn

In this workshop, you will:

- Navigate the OnDemand portal and understand its layout
- Upload, download, and manage research data through a graphical interface
- Access command-line shell through your web browser
- Launch interactive Jupyter notebooks and RStudio for data analysis
- Submit batch computing jobs to the cluster
- Monitor job progress and retrieve results

## Workshop Overview

This is a beginner-friendly introduction to OnDemand, designed for users new to HPC who prefer graphical interfaces over command-line tools.

### Episode 1: What is OnDemand?
Learn why OnDemand is valuable and how it differs from traditional SSH access.

### Episode 2: Dashboard Navigation
Explore the main interface and find key menu items and settings.

### Episode 3: File Manager
Manage your data files, understand storage locations, and transfer files.

### Episode 4: Shell Access
Use the web terminal for command-line computing when needed.

### Episode 5: Interactive Applications
Launch Jupyter notebooks and RStudio directly from your browser.

### Episode 6: Job Management
Submit batch jobs and monitor their progress without writing SLURM scripts.

## Time Requirements

- Total workshop time: Approximately 2.5 hours
- Each episode: 20-30 minutes including exercises
- Hands-on exercises: 15 minutes per episode

## Prerequisites

Before starting this workshop, ensure you have:

1. **Pomona College account credentials**
2. **DUO Multi-Factor Authentication** configured
3. **Active HPC account** approved by your PI
4. **Web browser** (Chrome, Firefox, Safari, or Edge)
5. **Internet connection** stable enough for interactive applications

## What You Need Before Starting

- Valid @pomona.edu username and password (not email format)
- DUO authentication configured (mobile app or SMS phone number)
- Approved HPC account on Sagehen cluster
- Modern web browser (Chrome, Firefox, Safari, or Edge, updated within 6 months)
- Stable broadband internet connection (minimum 2 Mbps recommended)

If you're missing any of these, contact its-hpc@pomona.edu to request setup before the workshop.

4. Complete DUO MFA verification
5. Welcome to OnDemand!
