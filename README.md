# OnDemand Portal Orientation

Pomona College HPC Workshop Series

## Overview

This workshop teaches how to access and use Sagehen HPC resources through the OnDemand web portal. Learners will navigate the dashboard, manage files graphically, launch interactive applications like Jupyter and RStudio, submit batch jobs, and monitor computations, all without requiring command-line knowledge.

## Episodes

1. **What is OnDemand?**: Understand the web portal's purpose, benefits, and how it differs from SSH access
2. **Dashboard Navigation**: Learn the OnDemand interface, find key features, and access different tools
3. **File Manager**: Upload, download, and organize research data using the graphical file browser
4. **Shell Access**: Use the web-based terminal for command-line computing when needed
5. **Interactive Apps**: Launch Jupyter notebooks, RStudio, and other interactive applications directly from your browser
6. **Job Management**: Submit batch jobs using web forms and monitor computation progress

## Prerequisites

- Valid Pomona College credentials
- DUO multi-factor authentication enabled
- Active HPC account approved by your principal investigator
- Web browser (Firefox, Chrome, Safari, or Edge)

## Learning Objectives

After completing this workshop, learners will be able to:
- Access OnDemand and navigate the main dashboard
- Upload, download, and organize files through the web interface
- Use the web-based terminal for command-line access
- Launch Jupyter notebooks and RStudio for interactive computing
- Submit batch jobs without writing SLURM scripts
- Monitor job status and view outputs in real-time
- Request GPU resources through the web interface
- Troubleshoot common access and application issues

## Target Audience

Researchers new to HPC who prefer graphical interfaces, or anyone wanting to access Sagehen resources without SSH knowledge. Particularly useful for desktop/tablet users and those unfamiliar with command-line tools.

## Duration

Approximately 2 to 2.5 hours including hands-on exercises.

## Technical Requirements

- Internet connection
- Modern web browser (Firefox, Chrome, Safari, or Edge)
- Pomona College login credentials
- DUO MFA access
- Sagehen HPC account
